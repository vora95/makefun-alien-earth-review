A small program that writes one single-line review of planet Earth by an alien tourist (88 characters) to `/output/entry.txt`: the locals drive to a building to walk in place on a belt. 4/5, would walk again.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
